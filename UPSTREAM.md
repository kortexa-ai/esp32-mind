# Upstream

This project began as an MIT-licensed copy of
[`slvDev/esp32-ai`](https://github.com/slvDev/esp32-ai) at commit
`74744182329f08d7a1badc97e47576ef527532a0`.

Copyright (c) 2026 Viacheslav Sierbov.

The original repository demonstrated a 28.9M-parameter PLE TinyStories model on
an ESP32-S3 with 16 MB flash. `esp32-mind` adapts the design for the Seeed Studio
XIAO ESP32-S3 with 8 MB flash and adds a USB serial prompt/response interface.
